# AI 缓存与访问保护：本地候选验收

日期：2026-10-01。候选后端：`direct-v6.3-cache-guard`。本次未合并远程分支、未发布腾讯云、未修改线上环境变量。

## 这次解决什么

- 反复进入相同赛事或热点，优先复用已成功的分析。
- 热点抓取时间、热度排名和评分变化不单独触发重新分析；标题、摘要、来源链接等实际材料变化会失效。
- 实时赛事不能沿用数天前的分析。正在进行的比赛分析缓存为1分钟。
- 网络失败后赛事数据可以有限重试；读到新鲜缓存也保留下一次轮询。
- 同一运行实例中，重复的在途模型请求只执行一次。个人 Key 与共享 Key 的服务端缓存隔离。
- 自动 AI 分析不再因失败立即发起第二次付费请求；上游失败进入30秒冷却。
- 内容生成不保存完成结果缓存，“重新生成”会发起新请求；同时到达的相同请求仍合并。
- 已配置共享付费 Key 时，默认拒绝匿名访问。个人 Key 的调用不要求共享访问口令。

## 缓存与失效

| 层次 | 内容 | 有效期与边界 |
| --- | --- | --- |
| 浏览器 | 成功的热点分析 | 7天；材料语义字段变化失效，不缓存 fallback/error |
| 浏览器 | 成功的比赛分析 | 实时1分钟，其余7天；比赛事实或基础选题变化失效 |
| 服务端运行实例 | 热点、比赛分析 | 热点与非实时比赛默认10分钟，实时比赛1分钟；最多128条，超出淘汰最早条目 |
| 服务端运行实例 | 内容生成 | 只合并在途请求，不复用已完成文案 |
| 服务端运行实例 | 上游失败 | 相同请求30秒冷却；不把失败当成功缓存 |

Next.js 热点审稿也有短时缓存。缓存不会让未完成的模型审核变成可发布；事实审核规则仍会保留待人工确认状态。云函数兼容路径不承诺每一种生成、审核操作都具有完成结果缓存。

浏览器缓存是当前设备的材料副本，不是账号权限系统；共享电脑应按需清理。服务端缓存含凭据的不可逆摘要，不把明文 API Key 当作缓存键。

## 调用保护

服务端可配置以下变量，均不是 `NEXT_PUBLIC_*`：

| 变量 | 默认行为 |
| --- | --- |
| `AI_ACCESS_TOKEN` | 共享 AI 访问口令；设置后缺失或错误返回401 |
| `AI_ALLOW_PUBLIC` | 默认不开放；只有显式值 `true` 才允许无口令共享调用 |
| `AI_MAX_CONCURRENT` | 每个运行实例同时最多2个不同模型请求，上限可配置到8 |
| `AI_MAX_HOURLY_CALLS` | 每个运行实例每小时最多60次，上限可配置到1000 |
| `AI_MAX_DAILY_CALLS` | 每个运行实例每天最多200次，上限可配置到5000 |

次数按 UTC 固定小时、固定日窗口统计，不是滚动窗口；模型真实尝试消耗次数，命中缓存和同请求合并不重复计数。失败也消耗次数。输入长度与输出 token 另外有限制。

没有配置模型 Key 时，免费本地规则仍可运行。共享 Key 已配置但没有口令或显式公开策略时返回403。不能为了消除报错直接开放公开共享调用。

口令用足够长的随机值，在腾讯云服务端私密设置。使用者在产品设置页填写口令，仅存入当前标签页的 sessionStorage；个人 API Key 仍遵循原设置页的 localStorage 行为。保存口令只表示已保存，不代表服务器已验证。

### 不要夸大保护能力

这是轻量访问口令和运行实例限额，不是完整账号登录系统，也不是全局财务预算。多实例、进程重启、Serverless 隔离均可能产生独立计数。扩大公开使用前仍需要共享配额存储、用户身份、供应商预算和监控告警。没有记录实际模型 token 与价格，不能据此编造节约金额。

## 发布顺序

1. 将前端候选建立在正确的远程分支上，解决主分支与 `competition-static` 的版本差异；不要把这个脏工作区直接整体推送。
2. 先验证并发布含共享口令设置、AI 请求头和事实展示修复的前端。仅部署后端 ZIP 不会更新前端。
3. 在腾讯云私密环境变量中设置访问策略。不要把模型 Key 或口令放进公开代码、截图、答辩文件或前端构建变量。
4. 运行发布预览，再按现有保护环境流程执行代码更新。若共享 Key 没有明确访问策略，脚本会在备份和代码更新前停止。
5. 核对公开版本、基础健康检查，以及一个不含敏感材料的完整案例。健康检查通过不代表付费模型、版权、移动端或真实点击流程均通过。

发布脚本不会自动修改线上环境变量，也不会自动回滚；现有加密备份与人工回退边界不变。
