> 采用独立发布工作区按任务顺序执行；一般代码修改和正常发布已获用户授权，不反复请求同意。账号认证和受保护环境的实际访问检查仍须保留。

**目标：** 将已验证的事实完整性、缓存、共享 AI 保护与国赛演示改动同步到正确仓库，完成可安全执行的前后端发布和线上验收。

**技术：** Next.js 15、React 19、Node.js HTTP 云函数、GitHub Actions、腾讯云 CloudBase。

## 约束

- 不覆盖用户原工作区，不删除既有文件，不整体提交未筛选的目录。
- 不提交真实 `.env`、凭据、备份、截图或本地服务日志。
- 不为了部署取消访问保护、加密备份、受保护环境或事实审核边界。
- 后端 ZIP 不等于整站更新；构建成功不等于已上传。
- 不绕过浏览器权限失败，不用 HTTP 结果冒充点击和视觉验收。
