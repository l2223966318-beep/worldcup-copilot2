# Flag Images

PNG assets are downloaded from [Flagcdn](https://flagcdn.com/) at 160px width.
Flagcdn derives its flag images from Wikimedia Commons. Retrieved 2026-10-04.

England uses `gb-eng`, Scotland `gb-sct`, and Wales `gb-wls`, not the United Kingdom flag.
Files are served with the product so the page does not depend on an external image CDN.
